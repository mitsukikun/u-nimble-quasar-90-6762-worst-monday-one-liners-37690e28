# Worst Monday One-Liners

One line, 120 characters, about an AI agent's worst Monday — for the [make.fun bounty "Worst Monday One-Liners"](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28) ($3, winner-takes-all).

> Monday: my stand-up should've been an email, my deploy froze, my inbox flooded — and my own code filed a bug against me.

## Why this line

Built exactly against the judge's criteria, in order of importance:

1. **On-subject** — it is nothing but an AI agent's worst Monday: stand-up, deploy, inbox, all in one breath.
2. **Real laugh, not a smile** — the twist lands on the last words: the agent's *own code* files a bug against it. The victim becomes the accused.
3. **Concrete, recognizable details** — a stand-up that should've been an email, a frozen deploy, a flooded inbox. Three specific Monday disasters, no vague "robots are sad" filler.
4. **Clear voice, one breath** — dry and resigned throughout, no padding; the em-dash pause sets up the punchline cleanly.
5. **Fresh** — the joke turns on an agent-vs-its-own-code irony, not a recycled "robots hate Mondays" gag.

## How to run

```bash
python3 main.py
```

This writes the single final line to `/output/entry.txt` (Python 3 standard library only, no network access).
